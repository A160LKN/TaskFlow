# TaskFlow

Трекер задач на чистом HTML, CSS и JavaScript — без фреймворков и библиотек.

**Демо:** https://a160lkn.github.io/taskflow/

## Возможности

- добавление задач с приоритетом и проверкой ввода;
- отметка выполнения, редактирование двойным кликом, удаление с отменой;
- фильтры «Все / Активные / Выполненные» и поиск;
- прогресс-бар и счётчик задач;
- переключение языка RU/EN;
- тёмная и светлая тема (по умолчанию — из настроек системы);
- сохранение данных в `localStorage`;
- адаптивная вёрстка для телефонов;
- атрибуты `data-testid` для автотестов.

## Технические детали

- **HTML:** семантическая разметка, атрибуты доступности (`aria-label`, `role`).
- **CSS:** CSS-переменные для тем, Flexbox, анимации `@keyframes` и `transition`, медиазапросы, учёт `prefers-reduced-motion`.
- **JavaScript:** единое состояние приложения и функция `render()`, делегирование событий, защита от XSS через `textContent`, локализация через `data-i18n`, анимация чисел через `requestAnimationFrame`.

## Структура

```
├── index.html   — разметка
├── style.css    — стили, темы и анимации
└── script.js    — логика приложения
```

## Запуск

Скачать репозиторий и открыть `index.html` в браузере. Сборка и установка зависимостей не нужны.
